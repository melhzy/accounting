# `models/recipes/windows/` — Windows + RTX 4090 Laptop training recipe

Native-host recipe (no container) for the dormant Windows row. Hardware context:
`.meta/hardware.md` "Dormant host details — Windows + RTX 4090 Laptop". Run-id
scheme: `.meta/ROADMAP.md` §1. Planned run-id (alive, not yet executed):
`qwen3-4b-bf16-lora-s00-r0`.

The recipe is **bf16 LoRA**, not QLoRA — the 16 GB VRAM ceiling on the 4090
Laptop tolerates bf16 r=16 at seq 2048 with grad-accum=8, and bf16 avoids the
Windows bitsandbytes ergonomic tax. QLoRA is held as the OOM-recovery fallback,
not the default.

## Run

```powershell
# from repo root
powershell -ExecutionPolicy Bypass -File models\recipes\windows\launch.ps1
```

`launch.ps1` will:

1. Locate the `unsloth` conda env (errors clearly if absent or if `conda` is not on PATH).
2. Pre-flight: assert `torch.cuda.is_available()` and assert `vllm` is **not** installed (its missing `vllm._C` extension breaks `import unsloth` on Windows).
3. Set `HF_HOME=D:\hf_cache` if unset, so the ~4 GB Qwen3-4B base download goes to the larger free-space drive.
4. Launch JupyterLab on `127.0.0.1:8888` from the repo root.

Override the port: `$env:JUPYTER_PORT=9999; powershell -File models\recipes\windows\launch.ps1`.

## Connect

**Browser**: open `http://127.0.0.1:8888/lab` and navigate to
`models/recipes/windows/qwen3_4b_seed00_bf16_lora.ipynb`.

**VS Code**:
1. Install the *Jupyter* extension if absent.
2. Open the notebook file in VS Code.
3. `Ctrl-Shift-P` → *Jupyter: Specify Jupyter Server for Connections* →
   *Existing* → enter `http://127.0.0.1:8888/?token=` (empty token field).
4. Select the kernel; cells run in the host `unsloth` conda env.

## Row-specific knobs (when Windows is ACTIVE)

| Knob | Value | Why |
|------|-------|-----|
| Quantization | bf16 LoRA, r=16, α=32 | 16 GB VRAM ceiling; bf16 avoids Windows bitsandbytes friction |
| Batch | 2 (per-device), grad-accum=8 → effective 16 | sm_89 + 16 GB envelope |
| Seq length | 2048 | matches DGX Spark row for cross-row comparability |
| `dataloader_num_workers` | **0** | Windows uses spawn → re-imports notebook module → Jupyter chokes |
| `HF_HOME` | `D:\hf_cache` | D: has more free space than C: (167 GB vs 105 GB at probe) |
| vLLM | **must be absent** | `vllm._C` is Linux-only; presence breaks `import unsloth` |
| Serving | Unsloth-native inference; llama.cpp/Ollama for portable runs | no vLLM on Windows |
